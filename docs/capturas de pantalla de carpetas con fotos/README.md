# Capturas del archivo fotográfico del MATP

Capturas de las carpetas de fotos que el museo guarda en Google Drive, compartidas en la reunión del 2026-10-31.
Se guardan aquí **con autorización del museo**, solo como referencia para diseñar la importación del archivo
fotográfico (change `importacion-fotos-a-catalogo`). No son datos de prueba: los fixtures siguen siendo sintéticos
(`data/fixtures/`).

Lo que muestran está resumido en `openspec/changes/importacion-fotos-a-catalogo/proposal.md` (formas de nombre
F1–F6 y carpetas de rango) y las preguntas abiertas en `docs/preguntas-contraparte.md` (AF1–AF6).
